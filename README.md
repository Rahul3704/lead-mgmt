<h2>#Lead Management System </h2>

A full-stack Lead Management System built with **React, Node.js, Express.js, and MongoDB**. It allows users to submit and manage leads through a simple web interface and REST APIs.

## Features

* Create, view, update, and delete leads
* RESTful API integration
* MongoDB Atlas database
* Email confirmation for new lead submissions
* Responsive React frontend
* Postman API testing

## Tech Stack

**Frontend:** React, JavaScript, CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB Atlas
**Tools:** Git, GitHub, Postman

## Project Structure

```text
Lead-Management/
├── frontend/
└── backend/
```

## Run Locally

```bash
# Clone repository
git clone <repository-url>

# Backend
cd backend
npm install
npm start

# Frontend
cd frontend
npm install
npm run dev
```

Create a `.env` file in the backend and add your MongoDB connection string and required email configuration.
